## II. Оценка по мировым стандартам

### Что соответствует лучшим практикам

1. **Самодостаточность файлов** — каждый HTML работает офлайн, без серверов, без трекинга. Соответствует принципу single-file web apps (как TiddlyWiki, Are.na, single-file ZIM).

2. **Эпистемическая честность** — каждый тезис маркирует «что мы НЕ знаем». Соответствует принципам Cochrane reviews, Preregistration, Open Science Framework.

3. **Адаптивность через clamp()/min()** — не @media-ступени, а непрерывная интерполяция. Соответствует CSS spec Level 4 (clamp, min, max — 2020+). Используется Mozilla Developer Network, W3C.

4. **prefers-reduced-motion** — WCAG 2.1 SC 2.3.3. Соответствует W3C accessibility standards.

5. **6 эпох с анахронизм-чеком** — соответствует практике History of Ideas (Lovejoy, Berlin), Begriffsgeschichte (Koselleck), Cambridge School (Skinner).

### Что отстаёт от лучших практик

1. **Шрифты не встроены** — Google Fonts загружаются при первом открытии. Полная автономия требует @font-face base64. Заявление тезиса 33 («самодостаточен») не вполне выполняется.

2. **Нет версионирования** — нет Git-репозитория. Все версии лежат в плоской файловой системе. Лучшие проекты используют Git + семантическое версионирование (semver).

3. **Нет автоматических тестов** — Playwright-проверки делаются вручную, в каждом сеансе. Лучшие проекты имеют CI/CD pipeline (GitHub Actions, GitLab CI).

4. **Нет README** — пустой файл. Любой, кто откроет репозиторий, не поймёт, что здесь.

5. **Разрозненные версии** — v18.1, v19, epochs — три разных файла, три разных архитектуры. Нет единого «входа» в проект.

6. **Контент v19 (33 тезиса) содержит анахронизмы** — именно те, которые были исправлены в epochs.html. Но v19 остаётся как «актуальный». Несоответствие.

## III. Алгоритм действий (ритуал дома)

### Закон дома

> **Человек не должен заниматься тем, что может делать сам агент без него.**
> **Поработал? Сделал? Убрал за собой. Никаких уведомлений.**

### Конечный автомат (state machine)

```
[state: idle]
    ↓ (получена задача)
[state: analyse]
    ↓ (определены блоки)
[state: execute]
    ↓ (готов артефакт)
[state: validate]
    ↓ (проверки пройдены)
[state: clean]
    ↓ (мусор удалён)
[state: report]
    ↓ (краткий отчёт)
[state: idle]
```

### Правила автомата

1. **Каждая задача → артефакт** (файл в download/)
2. **Каждый артефакт → валидация** (Playwright или эквивалент)
3. **Каждая валидация → очистка** (временные файлы удаляются)
4. **Каждая очистка → отчёт** (краткий, без листания файлов)
5. **Каждый отчёт → idle** (дом чист, ничего не висит)
6. **Никаких уведомлений** — агент не спрашивает «что дальше?», если задача определена
7. **Никаких висящих процессов** — после отчёта всё закрыто

### Что агент делает автоматически

| Задача | Автоматизация | Человек не трогает |
|--------|---------------|-------------------|
| Веб-поиск источников | z-ai web_search CLI | ✓ |
| Генерация HTML/Python | Write + Bash | ✓ |
| Playwright-валидация | python3 + playwright | ✓ |
| Очистка временных файлов | rm | ✓ |
| Подсчёт строк/байтов | wc, du, ls | ✓ |
| Проверка анахронизмов | Python regex script | ✓ |
| Сохранение финала | Write to download/ | ✓ |

### Что требует человека

| Задача | Почему |
|--------|--------|
| Определение направления проекта | Только человек задаёт вектор |
| Финальное одобрение тона/стиля | Вкус — не алгоритм |
| Решение о публикации | Этическое решение |
| Отзыв токенов доступа | Безопасность — ответственность человека |

## IV. Состояние проекта Linguistic Code

### Текущая ситуация

Проект находится в точке **расхождения двух линий**:

```
ЛИНИЯ A: v17 → v18 → v18.1 → v19 (тезисы с анахронизмами)
    ↓
    Проблема: RAM, lossy compression, JPEG — в античной эпохе

ЛИНИЯ B: epochs.html (6 эпох, без анахронизмов)
    ↓
    Проблема: только 6 разделов, нет соматической ловушки, нет 33 тезисов
```

### Что нужно для сингулярности

**v20 «Хронотоп»** — единый файл, который:

1. **Экраны 0-5** (ловушка) — берёт из v19 без изменений
2. **Экран 6** (манифест) — заменяет 33 анахроничных тезиса на **6 разделов-эпох** из epochs.html
3. **Адаптивность** — берёт clamp()/min()/ariadne-thread из v19
4. **Анахронизм-чекер** — встроенный скрипт, который при сборке проверяет, что запрещённые слова не появляются не в своей эпохе
5. **Самодостаточность** — шрифты встроены как base64 (тезис 33 без оговорки)
